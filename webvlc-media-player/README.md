WebVCL-Media-player-
A modern VLC-inspired media player for the web featuring local file playback, demo multi-cloud integration, advanced audio/video rendering controls, subtitle management, watch-later, playlists, long-video optimization, and professional playback settings—built for scalability and future desktop expansion.

Run Locally
Prerequisites: Node.js

Install dependencies: npm install
Set the GEMINI_API_KEY in .env.local to your Gemini API key
Run the app: npm run dev
